# CanIRunAI 0.2

面向 Apple Silicon Mac 的本地 AI 应用：检测硬件、推荐适配模型、部署运行、私密地进行文字和图片聊天。

## 下载与启动

**[下载完整源码运行包](./CanIRunAI-v0.2.0.zip)**。其中包含完整目录结构、前后端源码、依赖锁文件、启动器、模型注册表、测试和中文使用说明，共 127 个文件。

1. 安装 Node.js 24，解压 ZIP。
2. 在解压后的 CanIRunAI 文件夹中双击 `Start CanIRunAI.command`。
3. 首次运行安装依赖并构建网页，随后打开 `http://localhost:3000`。
4. 需要手动配对时，输入启动终端显示的 8 位配对码。保持终端运行。

这是需要 Node.js 的本地运行包，尚不是签名、公证的独立 macOS .app。模型权重按需从官方来源下载，不包含在压缩包中。

## 功能

- 简体中文界面，自动检测 Apple Silicon 硬件。
- 27 个模型版本、15 个系列的精选本地目录，2026-09-08 核验。
- 按实际文件大小、KV 缓存和可用内存推荐模型，支持搜索和分类筛选。
- 检查最低 Ollama 版本与固定模型摘要；部署、启动、停止、删除和本地速度测试。
- 本地流式对话；支持视觉的模型可接收上传、粘贴或拖拽的图片。
- 浏览器本地保存图文记录，可关闭保存和清空记录。
- 带认证的本机 Bridge 和 OpenAI-compatible API。

## 验证与范围

22 项自动测试通过，TypeScript 检查与网页正式构建通过。Qwen 3 Mini 完成真实文字推理测试；Qwen 3.5 0.8B 完成真实图片 HTTP 与流式输出测试，其余型号主要完成官方元数据核验。精选目录不等同于官方全部模型。
